# 自动课程术语库（试运行分支）

默认关闭。只有运行环境设置 `AUTO_COURSE_TERMS=true`，LectureRunner 才启用。
未合并到 main，不改变当前正式定时任务。

摘要与最多 15 个新词由同一次模型请求返回 JSON；邮件和 Markdown 只使用
`summary` 字段，关键词独立保存。DeepSeek 保持思考模式。没有额外的关键词 API 请求，
但证据引用和结构化输出会增加 token，用量并非完全不变。

Python 检查术语、来源及连续引用是否真实存在于输入材料，同时检查该词是否出现在
摘要的非补充、非疑点段落中。只允许简短中英文词条；排除课程事项、网址、控制字符、
常见指令词。没有有效词条也照常交付摘要。

PPT/云端复核直接支持的词可启用；仅 ASR 支持的词需在至少两个不同课次出现。
这只是降低错误循环的门槛，不是准确率证明，OCR 和云端也可能重复出错。
用 course_id 隔离词库，每个词保留来源引用和 sub_id，写入原有加密数据库的
`meta` 表（`auto_glossary:<course_id>:<sub_id>`），不提交到公开提示词文件。
并发数据库合并按每课次更新时间保留较新记录；被删除课次及正在重跑的同一课次不
作为识别提示来源。同一课次重跑不会被算作第二次独立支持。

读取最近 100 次有效课次，最多启用 30 个自动词；与人工词库去重后限制 30 个。
本分支的 Qwen 全量识别、LLM 疑点筛选和豆包热词使用同一份历史词库。
词库仅作为识别上下文提示，不得把关键词当作强制替换规则；main 的线上引擎不随本分支改变。

独立摘要恢复工作流可设置 `automatic_terms=true` 验证同次提取，候选和摘要只写入
加密测试产物，不会写正式数据库或发送邮件。此测试结果不自动加入正式词库。

暂未新增前端词条删除/锁定界面；保留现有人工词库。若以后新增界面，需要先设计
持久化禁用标记，避免删除后模型又自动收回该词。
