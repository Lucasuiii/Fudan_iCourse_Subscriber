# 审计修复范围与验证

本次按确定的安全、失败状态和数据一致性问题修补，保留现有课程选择、播放回退、ASR 切片/队列、复核额度、摘要和邮件收据规则。没有在本次修改中启动真实课程、发送邮件、写正式数据库或修改线上定时规则。

## 已采纳

| 清单建议 | 核对结果与修改 |
| --- | --- |
| 搜索结果 Stored XSS | 确认存在。对每个原文片段转义，匹配处只插入 `<mark>`，最终 DOMPurify 只允许无属性的 `<mark>`；不匹配分支也转义，清洗库不可用时只返回转义文本。 |
| 其他 HTML 输入路径 | 当前两个 `x-html` 分别为摘要 Markdown 和搜索高亮。摘要仍经过 DOMPurify，并限制输入为 HTML profile；KaTeX 在清洗之后渲染公式。 |
| 课程枚举 false success | 确认存在。返回成功课程、失败课程及任务，正常空扫描成功；有失败时保留并处理成功课程，旧入口和正式流程最终明确失败。正式队列保存枚举审计，旧检查点不强制新增字段。 |
| 全仓库 CI | 新增独立 `CI / test`，所有 PR 和 main push 无路径过滤，执行全部 unittest（含真实 DOM 清洗测试）。保留原 Qwen 专项 CI，不向基础 CI 提供 Secrets，不下载或启动 ASR 模型。 |
| SQLite 外键 | `Database` 连接启用并检查 FK；课次快照和汇总清理按子表到父表删除。重复课次插入仅忽略主键冲突，不再把 FK 错误吞成“已存在”。 |
| 数据库时间戳 | 新写入统一带 UTC offset；历史无时区值保持原样，前端 Date 仍支持两种格式。不猜测旧数据的时区或迁移历史时间。 |
| SMTP 超时 | 主邮件与导出入口增加 30 秒 socket 超时；主入口记录 connect/login/send 阶段及异常类型，不输出私人地址、凭据或异常正文。导出认证失败关闭连接。 |
| docs 忽略规则 | 移除 `docs/*` 及对应例外，新增正式 Markdown 文档可正常跟踪；保留现有 `docs/specs/` 忽略范围。 |
| `.env.example` | 按当前 config.py 更新模型密钥、URL override、课程排除/日期 override、多收件人配置；移除 SenseVoice。只放虚构占位，不放真实课程编号或凭据。环境变量仍需按现有本地运行方式导入，并未新加 dotenv 读取。 |
| 安全失败诊断 | 当前 main 已有 prepare 的稳定失败码、准备诊断和保留检查点修补；本次补 `course_enumeration_failed` 及不含课程编号/原始异常的成功失败计数审计。 |
| Python / JS schema 同步 | 增加五个表的字段名、类型、默认值、非空和主键元数据一致性测试，不引入 schema 生成工具。 |
| CDN 固定版本与 SRI | 所有十个远程脚本/样式采用完整版本；其中九个支持 CORS 的资源添加 SHA-384 SRI 和 anonymous crossorigin。固定版本的 Tailwind Play CDN 缺少 CORS 响应头，暂不添加会阻止加载的 SRI。其运行时内部资源（如 WASM、字体）不因此获得顶层 SRI 保护。 |

## 暂不修改

这些方向大多合理，但不能作为本轮小范围 bug 修复一并实施。

| 建议 | 暂缓理由 |
| --- | --- |
| Ruff 全仓库检查/格式化门禁 | 需要先建立基线并清理旧风格，否则会把功能修复扩大成全库格式化；先完成全量测试 CI，后续单独渐进加入。 |
| Viewer/Admin 拆分 | 涉及页面权限模型、凭据流程及管理操作迁移，需要独立设计和使用验证。已有 PAT/数据库密钥仅保存在浏览器标签页 sessionStorage，本次不扩大权限。 |
| CSP / 前端构建与完全自托管 | 需要兼容 Alpine 的表达式与内联指令、Tailwind 运行时及嵌套资源。直接添加严格 CSP 可能让页面失效；先修复 HTML sink、固定依赖并保护可校验资源。 |
| 拆分 production_qwen.py | 当前不是确定 bug，遵守“先补 CI 再重构”，后续仅做行为等价重构。 |
| schema 自动生成 | 先通过低成本一致性测试防漂移；生成工具单独处理。 |
| Python 全面依赖锁定 | 合理，但需在 Linux CPU/模型/视频/PDF 环境验证兼容并建立定期更新机制，不能直接把本机版本冻结为生产版本。本次只锁定新增的前端测试依赖。 |
| 删除/替换字体 | 字体许可与输出外观需单独核查；本次不改变既有 PDF 字体选择、不删除用户资产，也不把字体作为附件提供。 |

## 验证边界

- 自动测试使用临时数据库、模拟课程 API、模拟 SMTP 与本地 Git/加密产物，覆盖成功空扫描、部分/全部扫描失败、失败任务保留、FK、历史兼容和时间戳。
- 前端测试采用 JSDOM 和真实 DOMPurify/marked，包括 `img/onerror`、`svg/onload`、script、闭合标签、javascript URL、HTML 查询词、无匹配及清洗库缺失。还检查普通标题、表格、强调和公式文本未丢失。
- 本机浏览器检查实际页面初始化和 CDN 加载，不使用 PAT 或课程数据库；没有替代认证后的完整管理操作验证。
- 新全量 CI 自动触发不等于已经成为仓库保护规则的 required check。本次未更改 GitHub 权限或分支保护设置。
- 没有删除既有孤儿数据或迁移历史时间；其他既有低层 SQLite 导出/合并连接不在本轮统一改造成强制 FK，现有 merge/sharding/migration 测试继续执行。
- 真实课堂任务固定其原提交，本次修改不会应用到已经运行的概率论试跑，也不会重跑它。
